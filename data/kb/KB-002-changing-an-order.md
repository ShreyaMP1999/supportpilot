## When an order can be changed
You can change an order — add or remove items, swap sizes or colors, or update quantities — as long as its status is **Processing**. Once the status changes to **Packed** or **Shipped**, the order is locked and can no longer be edited.

## How to change an order
Go to **Account > Orders**, select the order and click **Edit order**. Make your changes and click **Save changes**. Any price difference is charged or refunded to your original payment method automatically. Guest customers can edit an order using the link in their confirmation email.

## If the order is already packed
If the Edit order button is unavailable, the order has entered fulfilment. You can cancel it if it has not shipped yet (see our cancellation article), or wait for delivery and start a free return for the items you no longer want.
